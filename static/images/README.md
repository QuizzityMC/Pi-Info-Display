# School Timetable Image

Place your school timetable image here as `timetable.png`.

## Instructions

1. Create or save your school timetable as an image (PNG format recommended)
2. Name the file `timetable.png`
3. Upload it to this directory: `~/Pi-Info-Display/static/images/`
4. Open the Pi Info Display and navigate to the "School Timetable" tab
5. Click the refresh button to load your timetable

## Image Requirements

- **Format**: PNG, JPEG, or other web-compatible image formats
- **Name**: Must be named `timetable.png`
- **Size**: Any size - the image will scale automatically to fit the display
- **Recommended**: For best results on the 7" display (800x480), use images around 800px wide

## Example

You can create a timetable using:
- Microsoft Excel or Google Sheets (export as image)
- Canva or other design tools
- Screenshot from your school's online portal
- Photo of a printed timetable

Once uploaded, the timetable will be displayed in the School Timetable tab and can be viewed at any time.
